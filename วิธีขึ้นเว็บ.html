วิธีขึ้นเว็บหน้า AR ส่องสัตว์

ใช้ GitHub Pages ฟรี ไม่ต้องติดตั้งโปรแกรม ทำผ่านเว็บเบราว์เซอร์ทั้งหมด ประมาณ 10 นาที

ขั้นที่ 1 สร้างที่เก็บไฟล์ (repository)

  1. เข้า github.com แล้วเข้าสู่ระบบ (ถ้ายังไม่มีบัญชี กด Sign up สมัครฟรี)
  2. กดปุ่ม + มุมขวาบน → New repository
  3. ช่อง Repository name พิมพ์ natureroute-ar
  4. เลือก Public แล้วกด Create repository

ขั้นที่ 2 อัปโหลดไฟล์

  1. ในหน้าที่ขึ้นมา กดลิงก์ uploading an existing file
  2. เปิดโฟลเดอร์ webar-site ใน Finder กด ⌘A เลือกทุกอย่าง แล้วลากไปวางในหน้าเว็บ
    (ต้องมีโฟลเดอร์ animals, ไฟล์ index.html, style.css, reservoir.html, thaplan.html, pangsida.html)
  3. รอให้รายชื่อไฟล์ขึ้นครบ แล้วกดปุ่มสีเขียว Commit changes

ขั้นที่ 3 เปิดเป็นเว็บไซต์

  1. กดแท็บ Settings ด้านบนของ repository
  2. เมนูซ้ายเลือก Pages
  3. ช่อง Source เลือก Deploy from a branch · Branch เลือก main และ / (root) แล้วกด Save
  4. รอ 1–2 นาที รีเฟรชหน้า จะเห็นลิงก์ เช่น https://ชื่อผู้ใช้.github.io/natureroute-ar/
ส่งลิงก์นี้กลับมา จะได้ทำ QR code ของสัตว์ทั้ง 21 ตัว และแก้ manuscript ให้

ขั้นที่ 4 ทดสอบบน iPhone

  1. เปิดลิงก์ใน Safari โดยตรง (ถ้าเปิดจาก LINE หรือ Facebook ให้กด “เปิดใน Safari” ก่อน ไม่อย่างนั้นปุ่ม AR จะไม่ทำงาน)
  2. เลือกโซน → เลือกสัตว์ → รอแถบสีเขียวด้านบนโหลดเต็ม → กด ส่องสัตว์ (AR)
  3. ส่องกล้องไปที่พื้น สัตว์จะปรากฏในพื้นที่จริง แคปหน้าจอไว้ใช้เป็นภาพใน manuscript

โมเดลบางตัวใหญ่ (หมูป่า 24 MB) ควรใช้ Wi-Fi

ขั้นที่ 5 เชื่อมกับเว็บ Wix

ในหน้า “ส่องสัตว์ด้วย AR” บน Wix ให้แต่ละโซนบนแผนที่ลิงก์ไปที่หน้าโซนใหม่ เช่น https://ชื่อผู้ใช้.github.io/natureroute-ar/reservoir.html (thaplan.html สำหรับทับลาน, pangsida.html สำหรับปางสีดา)
